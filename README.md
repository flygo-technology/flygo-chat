# Flygo Chat

App nhắn tin, gọi thoại/video cho đội nhóm, chạy trên máy chủ Mattermost (mặc định: máy chủ Flygo `https://chat.flygo.vn`).
Một mã nguồn Flutter cho Windows, macOS, Linux, Android và iOS.

- Hướng dẫn build và trỏ app về máy chủ Flygo: [docs/BUILD.md](docs/BUILD.md)

## Giấy phép

Mã nguồn công khai để xem và build dùng với máy chủ Flygo; không phải phần mềm nguồn mở. Xem [LICENSE](LICENSE).
